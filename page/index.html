在 magpie 中启用

从“扩展”添加并启用本插件后，MCP 会自动登记到资源库。

  1. 打开“资源库 → MCP 服务器”，找到 magpie-computer-use。
  2. 选择需要使用的 Agent，或点击“全部”，由 magpie 写入对应配置。
  3. 在 Agent 中重新连接 MCP，确认显示十个工具；首次控制目标应用时由你回答授权。

无需克隆仓库、运行安装命令或单独配置 Claude Code。若没有出现条目，请在“扩展”检查本插件的加载错误。
